防災ウォッチは、気象庁が公開しているデータだけを使って、 「いま日本のどこに警報が出ているか」「今日と明日の天気はどうか」「最近どこで地震があったか」を 1 時間ごとに自動でまとめている静的サイトです。人手は入っていません。

どこのデータを使っているか

気象庁の防災情報ページ（https://www.jma.go.jp/bosai/） が読み込んでいるのと同じ公開 JSON を使っています。具体的には次の 4 つです。

  • 気象警報・注意報（気象台ごと）
  • 天気予報・週間天気予報（気象台ごと）
  • 地震情報の一覧と、各地震の詳細（震源・規模・各地の震度）
  • 区域コードと名前の対応表

いずれも API キーや利用登録が要らない公開データです。加工しているのは「見やすく並べ替える」ところだけで、 数字や文言そのものは気象庁の発表をそのまま載せています。

警報・注意報の段階

気象庁の発表は重いほうから 特別警報 → 警報 → 注意報 の 3 段階です。 このサイトでは、特別警報を濃い赤、警報を橙、注意報を黄で表示しています。 「解除」された分は出ていない扱いにしています。

区域は「一次細分区域」（天気予報で使われる区分。東京都なら「東京地方」「伊豆諸島北部」など）で示しています。 市町村ごとの細かい発表状況は、気象庁のページでご確認ください。

震度について

震度は 1・2・3・4・5弱・5強・6弱・6強・7 の 10 階級です（震度 0 は「震度なし」として扱っています）。 地震の情報には、震源がまだ決まっていない段階の「震度速報」、震度の観測が無い「震源に関する情報」「遠地地震に関する情報」も含まれます。 そのため、震源や震度が「不明」と表示されることがあります。

「警報が出た回数のランキング」の数え方

気象庁は「過去にどの県に何回警報が出たか」という集計を配っていません。 そこでこのサイトでは、1 時間ごとの取り込みのたびに「そのとき出ていた警報・注意報」を日付ごとに記録し、 その積み重ねから数えています。当サイトが観測できた分の累積であり、気象庁の公式な統計ではありません。 サイトの公開前にさかのぼった分は含まれません。

更新のしかた

GitHub Actions が 1 時間ごとに動いて、気象庁からデータを取り込み、ページを作り直して GitHub Pages に配信しています。 サーバーは持たず、運用費はゼロです。ソースコードは GitHub にあります。

お願い

身の危険を感じたときは、このサイトではなく、気象庁・自治体の発表と避難指示に従ってください。 このサイトは取り込んだ時点の情報を並べているだけで、遅れや欠け、取り込みの失敗が起こり得ます。 命に関わる判断の材料にはしないでください。
