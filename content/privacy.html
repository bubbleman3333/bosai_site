集めている情報

防災ウォッチは GitHub Pages で配信している静的なサイトです。 入力フォーム、ログイン、会員登録はありません。当サイト自身が訪問者の個人情報を集めることはありません。

Cookie・アクセス解析

当サイトは Cookie を使っていません。独自のアクセス解析も入れていません。 ただし、配信元である GitHub Pages が、通信の記録（IP アドレス、ブラウザの種類など）をサーバーのログとして 保持することがあります。詳しくは GitHub のプライバシーに関する声明をご確認ください。

外部へのリンク

気象庁など外部サイトへのリンクがあります。リンク先での個人情報の扱いは、それぞれのサイトの方針によります。

掲載しているデータ

掲載しているのは気象庁が公開している気象・地震の情報だけで、個人に関する情報は含まれていません。

免責

当サイトの内容は気象庁の公開データを自動で加工したものです。 正確性・最新性を保証するものではなく、内容によって生じた損害について責任を負いません。 避難などの判断は、必ず気象庁および自治体の発表に従ってください。

変更について

この方針は必要に応じて変更することがあります。変更した場合はこのページを更新します。
